论文与研究Research

基于迭代源控制加速卷积传递函数的多通道非负矩阵分解 Accelerated Convolutive Transfer Function-Based Multichannel NMF Using Iterative Source Steering

APSIPA ASC 2025 · 新加坡Singapore

Accelerated Convolutive Transfer Function-Based Multichannel NMF Using Iterative Source Steering

Xuemaixie Xie, Xianrui Wang, Liyuan Zhang, Yichen Yang, Shoji Makino · Proc. APSIPA ASC, 2025, pp. 149–153

研究课题：统计信号处理中盲源分离算法迭代速度的优化 Topic: speeding up iterative blind source separation algorithms in statistical signal processing

  • 研究内容：多通道盲源分离在强混响场景下的高效求解问题。在卷积传递函数信号模型框架下的多通道非负矩阵分解方法的基础上，提出了基于 Iterative Source Steering（ISS）的加速方法。 Problem: solving multichannel blind source separation efficiently under strong reverberation. Building on multichannel NMF under the convolutive transfer function (CTF) signal model, I proposed an acceleration method based on Iterative Source Steering (ISS).
  • 算法实现：以无需矩阵求逆的 ISS 更新替代传统的 Iterative Projection（IP）更新，重新推导出解混矩阵的迭代公式，将每个声源、每个频点的更新复杂度由 O(M³) 降至 O(M²)，消除了随麦克风数立方增长的求逆开销。 Method: replaced the conventional Iterative Projection (IP) updates with inversion-free ISS updates and re-derived the demixing-matrix update rules, cutting the per-source, per-frequency cost from O(M³) to O(M²) and removing the inversion overhead that grows with the cube of the number of microphones.
  • 研究结论：基于 TIMIT 语音与 RWCP 混响数据，在 4/6/8 麦克风条件下完成了实验验证：在保持与 IP 方法相当或更优分离性能的同时，运行时间平均下降约 40%，并具有更好的数值稳定性和鲁棒性。 Results: in experiments with TIMIT speech and RWCP reverberation using 4, 6 and 8 microphones, the method matched or beat IP's separation performance while cutting runtime by about 40% on average, with better numerical stability and robustness.

项目经历Projects

  • 面向中文法律咨询的 Multi-Agent 系统Multi-agent system for Chinese legal consultation

    独立完成从 RAG 搭建到 Multi-Agent 的设计与实现，基于 vLLM 实现本地推理。 Designed and built the whole system on my own, from the RAG pipeline to the multi-agent layer, with local inference on vLLM.

    • RAG：基于现行法规与千条 QA 问答构建向量检索库，作为 agent 的长期语义记忆。针对中文法律检索中“语义相近但法域混淆、具体条号难以稳定命中”的问题，设计了“关键词检索 + 语义检索”的双路召回方案，并通过 RRF、法域预过滤、法规名与条号解析、法律相关性重排等机制提升检索质量；相比扩大召回数量或增加多路查询，该方案主要通过提高候选法条的相关性和排序位置来提升命中率。Recall@10 达到 83.0%，MRR@10 78.0%，p95 检索延迟约 320ms。 RAG: built a vector index from current statutes and about a thousand Q&A pairs as the agents' long-term semantic memory. Chinese legal search often returns passages that are semantically close but from the wrong area of law, and misses specific article numbers, so I designed dual-path recall (keyword + semantic search) with RRF fusion, legal-domain pre-filtering, statute-name and article-number parsing, and legal-relevance reranking. Rather than retrieving more candidates or adding more queries, it raises the hit rate by improving the relevance and ranking of candidate articles. Recall@10 reached 83.0% and MRR@10 78.0%, with p95 retrieval latency around 320 ms.
    • Agent 实现：设计了多 agent 的咨询流程，包含接待、律师、秘书、监管四个 agent 的 ReAct + Agent-as-Tool 编排，接入工具调用与多轮 memory。针对法律问答中“错法条、错引用、乱扩写”的问题，设计了证据优先的生成链路：先判断证据是否足够，不足则改写或拒答；生成后校验引用是否真实来自证据，最终审核。实现为可路由、追问、校验的 Agent 流程。另外设计并实现了合同审查与法律文书生成的 skill，沉淀 SOP 工作流，提高复用性与效率。 Agents: designed the consultation flow around four agents (receptionist, lawyer, secretary and supervisor) orchestrated with ReAct and agent-as-tool, with tool calling and multi-turn memory. To curb wrong statutes, wrong citations and embellishment, generation is evidence-first: the system checks whether the evidence is sufficient and otherwise rewrites the query or declines to answer; after generating, it verifies that each citation really comes from the evidence, then runs a final review. The result is an agent flow that can route, ask follow-up questions and verify. I also built skills for contract review and legal document drafting that capture SOP workflows for reuse and efficiency.
    • Harness 工程：对话历史以 JSON 形式落盘到本地，以 session 与 turn 为单位存储对话单元；保留用户事实与已引用法条，能继承上一轮的法域和法规名。长对话中自动压缩上下文、固定关键证据；会话结束后把成功 / 失败路径写入长期记忆，用于后续路由、检索和失败规避。 Harness engineering: conversation history is saved locally as JSON, stored per session and per turn, keeping user facts and cited articles so the next turn inherits the area of law and statute names. Long conversations get automatic context compression with key evidence pinned, and at the end of a session the successful and failed paths are written to long-term memory to guide later routing and retrieval and to avoid repeating failures.

  • 后训练范式中在策略蒸馏的消融实验研究Ablation study of on-policy distillation in post-training

    选用 Qwen3-8B 作为教师模型，Qwen3-1.7B 的 Instruct 与 Base 版本作为学生模型进行后训练，在 GSM8K 数据集上对比 SFT、off-policy 蒸馏与 on-policy 蒸馏（OPD）的效果。 Post-trained Qwen3-1.7B students (Instruct and Base) with a Qwen3-8B teacher, comparing SFT, off-policy distillation and on-policy distillation (OPD) on GSM8K.

    • 核心结果：Base 模型经过 OPD 后在测试集上达到 70.9% 准确率，较 SFT 绝对提升 3.3 个百分点，而梯度更新阶段的训练仅消耗 SFT 训练 FLOPs 的 27%。在 CoT 上，OPD 促使学生模型学会教师模型的“思考方式”。 Key results: after OPD the Base model reached 70.9% test accuracy, 3.3 points above SFT, while the gradient-update phase used only 27% of SFT's training FLOPs. On chain-of-thought, OPD led the student to pick up the teacher's way of thinking.
    • 灾难性遗忘：Instruct 学生模型的基准准确率为 74.7%，SFT 后反而降至 60.7%；OPD 则保持在 75.7%，无显著遗忘。KL 散度损失约束学生分布不过度偏离教师，减少了遗忘。 Catastrophic forgetting: from the Instruct student's 74.7% baseline, SFT dropped accuracy to 60.7%, while OPD held it at 75.7% with no significant forgetting. The KL-divergence loss keeps the student's distribution close to the teacher's, which limits forgetting.
